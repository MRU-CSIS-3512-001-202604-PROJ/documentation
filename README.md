## Clarifications and changes

Requirements documents get clarified as the term goes on. When that happens:

- **I post it to D2L**, so you get notified. Make sure your D2L notifications are actually turned on - that's the only push you'll get, and "I didn't see it" won't help you in December.
- The clarification also appears **inline, in the document itself**, tagged with the date it was added - like `[2026-10-31]`. Skim for those tags when you come back to a document.

**This repository is the authority.** D2L tells you _that_ something changed; the document here tells you _what_ it now says. A copy you downloaded in September is neither.
